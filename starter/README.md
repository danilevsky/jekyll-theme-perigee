# My Site

Starter for [jekyll-theme-perigee](https://github.com/danilevsky/jekyll-theme-perigee).

```sh
bundle install
bundle exec jekyll serve      # http://localhost:4000
```

Edit `_config.yml` (title, social links), `index.md` (home page sections), `_data/navigation.yml` (menu),
and add posts to `_posts/`. Push to GitHub with Pages source set to "GitHub Actions" to deploy.
