Perigee brings the look of [Gravity UI](https://gravity-ui.com/) to static sites built with Jekyll:
the same design tokens, typography and icons, without React.

## Features

- Light, dark and system color themes
- Built-in localization: UI strings, per-language URLs, `hreflang`
- Self-hosted Inter font with Cyrillic support

> Perigee is an independent project and is not affiliated with the Gravity UI team.

| Token | Purpose |
|-------|---------|
| `--g-color-base-brand` | Accent color |
| `--g-color-text-primary` | Main text |
