Perigee는 [Gravity UI](https://gravity-ui.com/)의 디자인을 Jekyll로 만든 정적 사이트에 그대로 가져옵니다.
동일한 디자인 토큰, 타이포그래피, 아이콘을 React 없이 사용합니다.

## 기능

- 라이트, 다크, 시스템 색상 테마
- 내장된 다국어 지원: UI 문자열, 언어별 URL, hreflang — 플러그인 없이
- 키릴 문자를 지원하는 자체 호스팅 Inter 폰트

> Perigee는 독립적인 프로젝트이며 Gravity UI 팀과 관련이 없습니다.

| 토큰 | 용도 |
|------|------|
| `--g-color-base-brand` | 강조 색상 |
| `--g-color-text-primary` | 기본 텍스트 |
